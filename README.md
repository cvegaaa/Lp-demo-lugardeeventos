# La Candelaria — Landing de Casa de Eventos

Landing page demo para una casa de eventos, enfocada en bodas y celebraciones en Montería.

## Qué resuelve

Presenta las instalaciones y servicios de un salón de eventos, con formulario para solicitar disponibilidad y cotización.

## Stack técnico

- React + TypeScript + Vite
- Tailwind CSS
- Supabase (formulario de contacto)

## Estado

Demo de portafolio.
